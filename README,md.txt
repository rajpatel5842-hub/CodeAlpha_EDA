# Diwali Sales Data Analysis - EDA

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Diwali Sales dataset using Python.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Data Cleaning
- Gender Analysis
- Age Group Analysis
- State Analysis
- Occupation Analysis
- Product Category Analysis
- Zone Analysis
- Marital Status Analysis
- Data Visualization

## Conclusion

The analysis helps understand customer purchasing patterns, sales distribution and important factors affecting sales.

## Project Files

- `Diwali Sales Data.csv` - Dataset
- `EDA_Project.ipynb` - EDA analysis
- `README.md` - Project documentation
